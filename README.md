# matheusvms.github.io

Personal academic website of Matheus Souza: https://matheusvms.github.io

Plain HTML, CSS and a few lines of JavaScript (the light/dark toggle), no build step.

- `index.html`: all content. To add a paper, copy one `<article class="pub">` block in the
  Publications section, paste it at the top and edit it (instructions are in the HTML comment).
- `style.css`: layout and colors (light and dark palettes at the top).
- `images/`: photo, paper thumbnails (~400 px wide) and logos. `og-card.jpg` is the preview image
  shown when the site is shared on LinkedIn, Slack, etc.

Design inspired by [Jon Barron's website template](https://github.com/jonbarron/jonbarron_website).
